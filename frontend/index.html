Diagnóstico pedagógico

Texto escrito pelo modelo local a partir dos números desta análise. Vale revisar antes de usar em documentos oficiais.

Como ler os índices

Acerto
Parcela dos alunos que marcou a alternativa correta. Abaixo de 30% a questão é difícil; de 30% a 50%, média; a partir de 50%, fácil.
Discriminação
Diferença de acerto entre os 27% de alunos com melhor nota e os 27% com pior nota. Ótima a partir de 0,40, boa de 0,30, razoável de 0,20. Abaixo disso é fraca: até os melhores alunos erraram.
Distrator
A alternativa errada mais escolhida. Quando ela passa a correta, costuma indicar um erro de conceito comum na turma.

Analisador de Provas

Projeto de Estágio Obrigatório em Ciência de Dados. Identifica fragilidades de aprendizagem a partir do desempenho dos estudantes em provas como o ENADE.

Estatística pela Teoria Clássica dos Testes. Temas e diagnóstico escritos por um modelo de linguagem que roda no próprio computador, então os dados dos alunos não saem da máquina.

Dados de exemplo: microdados do ENADE 2021, Ciência da Computação, publicados pelo INEP.
